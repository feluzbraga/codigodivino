# CÓDIGO DIVINO - versão para GitHub Pages

Arquivos:
- index.html
- style.css
- script.js

Como publicar:
1. Crie um repositório no GitHub.
2. Envie os três arquivos.
3. Em Settings > Pages, selecione Deploy from a branch.
4. Escolha a branch main e a pasta /root.
5. Salve e aguarde o GitHub gerar o endereço.

Observação:
As imagens foram mantidas usando os endereços CDN encontrados no HTML original do template Hostinger. Para uma versão totalmente independente, substitua essas URLs por arquivos locais na pasta /assets.
